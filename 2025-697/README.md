# Access request 2025-697 — Traffic count data, rue de Terrebonne

**Public body:** Arrondissement de Côte-des-Neiges–Notre-Dame-de-Grâce, Division du greffe
**Filed:** November 27, 2025
**Answered:** December 19, 2025, by the secrétaire d'arrondissement
**Released:** a spreadsheet of counts (`Comptage Terrebonne.zip`), two equipment data sheets, the notice of recourse

## What was asked

All traffic count data held by the borough for any location along rue de Terrebonne, for all vehicle types recorded, from June 1, 2024 to the date of the request; and any documentation indicating the manufacturer, model and exact location of the counting system(s).

## What was released

| File | Content |
|---|---|
| [`raw/response_2025-12-19.pdf`](raw/response_2025-12-19.pdf) | The borough's response letter, listing four enclosures |
| `raw/Comptage Terrebonne.zip` | Counter record, all vehicle types, to the date of the request *(to be added)* |
| `raw/ZELT_EVO_FICHE_PRODUIT.pdf` | Eco-Counter ZELT EVO product sheet: the inductive-loop bicycle counter on Terrebonne at Kensington *(to be added)* |
| `raw/VCU Scout Caractéristiques Techniques.pdf` | Data sheet of the counter's logging unit *(to be added)* |

Nothing was withheld. The counter's continuation to May 11, 2026, with bicycles by direction, was obtained under [2026-300](../2026-300/), which is where the winter 2025–26 analysis lives.
